### 👋 About / 关于我

I work on embedded systems and the storage stack underneath them — FAT32, SQLite, FlashDB, EXT4. I like rebuilding the wheel: implementing a format, a protocol, or a stream muxer from scratch is how I understand how it actually works.

我主要做嵌入式开发和存储技术栈：FAT32、SQLite、FlashDB、EXT4。喜欢把轮子重新造一遍——亲手实现一个文件格式、协议或码流封装，才能真正搞懂它为什么能转。

- 🧱 **Embedded** — C, device-side storage, firmware
- 💾 **Storage stack** — FAT32 / SQLite / FlashDB / EXT4
- 🎞️ **Streaming** — MPEG-PS stream encapsulation
- 🤖 **LLM black boxes** — building around models as APIs, not training them
- 🔁 **Wheel reinvention** — reimplementing formats and protocols to learn them

### 🧰 Selected projects / 做过的东西

| What I wanted to understand / 想搞清楚的事 | Project / 项目 | Stack |
|:---|:---|:---|
| EXT4 on Windows | [**Ext4WslHelper**](https://github.com/Yunheeee/Ext4WslHelper) — Access EXT4 SD cards through WSL2 + usbipd. Offline setup, single exe.<br>通过 WSL2 + usbipd 在 Windows 上访问 EXT4 SD 卡，离线安装，单 exe。 | `C++` `Win32` `WSL2` |
| FlashDB KVDB internals | [**flashdb_viewer**](https://github.com/Yunheeee/flashdb_viewer) — Browse sectors, search keys, filter states, export JSON.<br>解析并可视化 FlashDB KVDB 二进制文件，支持搜索、过滤和导出。 | `Python` `Flask` |
| SQLite file format | [**sqlite3-file-viewer**](https://github.com/Yunheeee/sqlite3-file-viewer) — Inspect the SQLite3 database file format with a PyQt5 GUI.<br>用 PyQt5 界面分析 SQLite3 数据库文件格式。 | `Python` `PyQt5` |
| Serial workflow | [**AutoInput**](https://github.com/Yunheeee/AutoInput) — Pick a window, then send serial commands line by line.<br>定位串口终端窗口，按行自动输入命令。 | `Python` `PyQt5` |

> Most of these started as a personal need to understand a format or workflow.<br />
> 大部分项目只是拆格式、折腾工作流时顺手留下的东西。
