### 👋 About / 关于我

I like the seams between systems — where a file format, a driver, or a protocol stops being visible to the user, and a small tool makes it usable again.

我喜欢系统与系统之间的接缝：当文件格式、驱动或协议对用户变成黑盒时，做一个小工具把它重新打开。

- 🔧 **Systems tooling** — Windows / Linux / WSL2 / USB
- 🧩 **Binary formats** — EXT4 / FlashDB / SQLite
- 🐍 **Python & C++** — PyQt5 / Flask / Win32 / CLI
- 🌱 **Currently exploring** — filesystem internals, embedded storage, automation

### 🧰 Featured tools / 代表项目

| Black box / 黑盒 | Tool / 工具 | Stack |
|:---|:---|:---|
| EXT4 SD card on Windows | [**Ext4WslHelper**](https://github.com/Yunheeee/Ext4WslHelper) — Access EXT4 SD cards through WSL2 + usbipd. Offline setup, single exe.<br>通过 WSL2 + usbipd 在 Windows 上访问 EXT4 SD 卡，离线安装，单 exe。 | `C++` `Win32` `WSL2` |
| FlashDB KVDB binary | [**flashdb_viewer**](https://github.com/Yunheeee/flashdb_viewer) — Browse sectors, search keys, filter states, export JSON.<br>解析并可视化 FlashDB KVDB 二进制文件，支持搜索、过滤和导出。 | `Python` `Flask` |
| SQLite file format | [**sqlite3-file-viewer**](https://github.com/Yunheeee/sqlite3-file-viewer) — Inspect the SQLite3 database file format with a PyQt5 GUI.<br>用 PyQt5 界面分析 SQLite3 数据库文件格式。 | `Python` `PyQt5` |
| Repetitive serial input | [**AutoInput**](https://github.com/Yunheeee/AutoInput) — Pick a window, then send serial commands line by line.<br>定位串口终端窗口，按行自动输入命令。 | `Python` `PyQt5` |
